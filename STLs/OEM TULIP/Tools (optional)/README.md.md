The TOOLS provided for Tulip Mod are there to help you with preparing and installing componants.

The Bearing Press Tool help locate and install the bearing to the correct hight.

The AB Pully Tool helps get the pullies set in the right spot on the motor shafts.

The Drill Hole Guide is for the two addictional holes needed for the tension idlers.

The Pin Cutting Jig is for those who are able to cut their own pins (others are availible ready to use from the links in the BOM)


Some tools carry a certain element of risk to the user!

If not used correctly these can injure / maim you so please use them wisely!

They are intended to help you cut and / or install parts for Tulip Mod.

If you have any doubt or questions about the safe use of these tools please reach out on the Voron Discord to either @driftrotor or @amekyras and we will do our best to guide you and answer any questions you might have.
